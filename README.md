# GuitarKit

기타 연습 도구 모음. 스케일, 코드사전, 메트로놈, 튜너를 한 웹앱에서 사용합니다.

![프리뷰](public/preview.png)

## 기능

### 스케일 연습 (`/guitar-scale`)

6현 프렛보드에 스케일을 시각화합니다. 5~24프렛까지 조절 가능하고, 메이저·자연 마이너·펜타토닉·도리안·믹소리디안·리디안·프리지안·화성 마이너·가락 마이너(상행형) 10종을 지원합니다. 메이저·메이저 펜타토닉·마이너 펜타토닉은 CAGED 코드 모양별 운지를 볼 수 있고, 나머지는 전체 포지션으로 표시합니다. 음을 눌러 소리를 들을 수 있습니다.

전체 음·스케일만·전체 음 위 스케일 강조를 전환할 수 있고, ‘음 찾기’로 특정 음의 모든 위치를 강조합니다. 도레미는 고정도법, 숫자는 선택한 루트 기준 인터벌입니다. 모바일에서는 줄 번호를 고정한 가로 지판을 스크롤합니다. 음 버튼의 터치 영역은 최소 44×44px입니다.

지판 설정과 백킹 트랙·메트로놈 BPM은 현재 브라우저에 저장됩니다. 다시 열면 설정은 복원되지만 소리는 자동 재생되지 않습니다.

지판 바로 위의 ‘시작 프렛 / 끝 프렛’에서 표시 범위를 선택합니다. 끝 프렛은 24까지, 한 번에 최소 4개 프렛을 표시하며 화면에 넘치는 지판은 좌우로 스크롤할 수 있습니다.

‘음 찾기 퀴즈 시작’에서 음→위치, 위치→음, 완전5도·옥타브, 메이저·마이너 3화음 구성음을 연습합니다. 전체/특정 줄, 0–5/0–12프렛, 자연음/모든 음을 선택하고 10문제를 풉니다. 결과에서 첫 시도 정답·재시도·정답 보기를 구분하며 틀린 문제만 복습할 수 있습니다. 완료 기록은 현재 브라우저에 최대 10개 저장하며, 진행 중 세션은 새로고침하면 초기화됩니다. 퀴즈 종료 후 기존 지판 설정으로 돌아갑니다. 3화음 연습은 구성음 하나씩 찾기이며 전체 코드 운지 훈련은 아닙니다.

‘반주 코드톤’을 켜면 현재 재생하는 코드의 근음·3음·5음이 지판에 표시됩니다. 주황색은 근음, 청록색은 나머지 구성음입니다. 123 표기도 재생 중 코드의 근음 기준으로 바뀝니다. 정지하거나 메트로놈으로 전환하면 원래 스케일 표시로 돌아갑니다.

### 코드사전 (`/chords`)

코드 구성음과 운지법을 다이어그램으로 보여주고 소리로 들려줍니다.

### 릭 연습 (`/lick-practice`)

4박 준비 → 기타 릭 1마디 듣기 → 직접 따라 치는 1마디를 반복합니다. 내 차례에는 기타 멜로디가 빠지고 A·E 저음 반주와 클릭이 유지됩니다. 직접 만든 A 마이너 펜타토닉 릭 3개, 4/4박자, 5–8프렛, 40–140 BPM을 지원합니다. 벤딩·슬라이드는 없는 입문 연습입니다.

8분음표 8칸의 TAB과 지판 위치가 같은 재생 순서에 따라 움직입니다. 음을 유지하는 칸과 쉼표를 구분하며, 정지 상태에서는 지판을 눌러 개별 음을 들을 수 있습니다. 속도는 브라우저에 저장되고, 릭·속도를 변경하거나 다른 탭으로 이동하면 정지합니다. 재시작은 항상 4박 준비부터 시작합니다. 마이크 녹음·채점은 하지 않습니다.

### 메트로놈 (`/metronome`)

BPM, 박자, 세분화를 조절할 수 있고 탭 템포와 사운드 6종을 지원합니다.

### 튜너 (`/tuner`)

마이크로 실시간 피치를 잡아 목표음 대비 편차를 보여줍니다. 헤드스톡 GUI에서 줄 번호(1~6번)만 고르면 되기 때문에 EADGBE 표기를 몰라도 튜닝할 수 있습니다. 튜닝 프리셋 8종을 지원합니다.

### 표기법

알파벳(C, D, E...), 계이름(도, 레, 미...), 인터벌(1, 2, 3...) 세 가지 표기법을 전환할 수 있고, 루트 노트는 12음 전체를 선택할 수 있습니다.

## 기술 스택

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Radix UI, Framer Motion, Tone.js

## 시작하기

```bash
pnpm install
pnpm dev
```

`http://localhost:3000`에서 확인합니다.

```bash
pnpm build   # 프로덕션 빌드
pnpm start   # 프로덕션 서버 실행
pnpm test    # 테스트 실행
```
