- C Major E 모양: 0–24프렛으로 변경. 390px에서 다음 구간 버튼을 두 번 눌러 6–10프렛으로 이동. 3번 줄 7프렛 D, 4번 줄 7프렛 A, 5번 줄 7프렛 E의 활성 강조를 스크린샷으로 확인. 2번 줄 7프렛 F#는 비구성음으로 구분.
- 390px: 접힌 설정 요약, 설정 펼침, 자연 마이너 버튼, 한국어 설명, CAGED 설명·버튼의 줄바꿈 확인. 지판의 줄 라벨은 가로 이동 시 고정.
- 자동 검증: Jest 5개 스위트·206개 테스트 통과. 과거의 프렛 범위 테스트는 출처 도표를 전사한 줄별 운지 테스트로 교체했으므로 이전 테스트 개수와 직접 비교하지 않는다. TypeScript 검사 통과. Google Fonts 접근 허용 후 프로덕션 빌드 통과.
- 잘못된 단순 음이름을 기대하던 `lib/scale-tests.ts`는 중복 레거시 스크립트여서 삭제했다. Git 이력에서 복구 가능하며, 실행 가능한 검증은 Jest로 통합했다.
