## 검증

- Jest 11개 스위트, 227개 테스트 통과.
- ESLint, TypeScript 검사, 소스 Prettier 검사, 타입 검사를 포함한 프로덕션 빌드 통과.
- `pnpm audit --prod --json`: 알려진 취약점 0건. 감사 당시 데이터 기준이며 안전 보증은 아니다.
- 현재 추적 파일과 로컬 Git 이력 100개에서 대표적인 GitHub·OpenAI·AWS 토큰 및 개인키 패턴 일치 없음.
- 환경 파일·인증서·로컬 개발 도구·커버리지 산출물의 Git 제외 규칙 보강.
- MCP로 Safari에서 메트로놈 시작·정지, 드럼을 켠 릭 연습의 준비·듣기·내 차례 표시와 정지 후 지판 버튼 복구를 확인했다.

비밀값 검사는 알려진 패턴에 한정된다. 미가져온 원격 이력, 임의 형식의 비밀값,
GitHub 설정, 외부 배포 환경은 검사하지 않았다. 실제 마이크 녹음·음질 평가는 범위 밖이다.

## 남겨둔 사항

- 코드 라이선스는 소유자 결정이 필요하므로 임의로 추가하지 않았다.
- 사용하지 않는 초기 템플릿 의존성은 이번에 일괄 삭제하지 않았다. 기능별 제거는 별도 변경으로 진행할 수 있다.
- 외부 피아노 샘플 로딩 실패의 재시도 UI와 오프라인 지원은 후속 개선 대상이다.
- 릭·반주·메트로놈은 전역 Tone Transport를 공유하므로 여러 플레이어의 동시 재생은 지원하지 않는다.
- 커밋·푸시·저장소 공개 설정은 변경하지 않았다.
